# 🐸 Frogger Clone (Unity)

A simple 2D arcade-style Frogger clone built in Unity as a personal learning project. The goal is to recreate the classic Frogger gameplay with basic movement, obstacles, and level progression.

## 🎮 How to Play

### ▶️ Run the Game
1. Download or clone the repository
2. Open the 'BawkerFinalBuild' folder
3. Run the executable 'Final.exe'

## 🕹️ Controls

- Arrow Keys / WASD → Move the chicken
- Works on Controller input as well
- Avoid cars and water
- Reach the haystacks to gain points

---

## 🎯 Features

- Classic Frogger-style movement
- Moving obstacles
- Basic level structure
- Built using Unity’s 3D system (adjusted for 2D feel)
